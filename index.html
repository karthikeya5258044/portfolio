ABOUT ME
IBM CERTIFIED · AI ANALYST

My path into AI/ML didn't start with a bootcamp — it started with curiosity, and a lot of debugging at 6 AM. I taught myself to code from the ground up: Python first, then Java and DSA, then Django, then the data stack — NumPy, Pandas, SQL, Power BI.

My first real "it's alive" moment was building Jarvis, a voice assistant running on Whisper for speech recognition, Ollama for local LLM reasoning, and pyttsx3 for speech — my introduction to actually wiring AI systems together instead of just calling an API.

From there I moved into automation, building AI agents with n8n and Ollama, then went deep into the fundamentals — machine learning, deep learning, and eventually generative AI: RAG pipelines, multi-agent systems, and the architecture behind transformers. That curriculum phase ended with a decision that still shapes how I work: stop accumulating theory, start shipping deployed systems.

That decision led to NeuroRAG, my first published research — combining EEG signal processing with RAG-based clinical assessment, now live on Zenodo. And it led to KRAG, my current flagship project: a multi-tenant RAG SaaS platform built backend-first, with hybrid retrieval, tenant-isolated vector storage, async processing pipelines, and JWT auth — engineered the way production systems actually need to work, not the way tutorials show it.

The system I'm building right now is a multi-agent orchestration layer on top of KRAG — an orchestrator/router directing specialist agents. It's the natural next step in a journey that started with a single voice assistant answering simple commands, and is now about building systems that reason, retrieve, and coordinate on their own.
